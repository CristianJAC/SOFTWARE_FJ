SOFTWARE FJ
============

Aplicación estable, modular y extensible que
implementa de forma rigurosa los principios de abstracción, herencia,
polimorfismo, encapsulación y manejo avanzado de excepciones,
garantizando que el sistema siga funcionando aun cuando se presenten
errores durante su ejecución.

Los servicios de sala y asesoría usan unidades como horas; el servicio de equipo
usa unidades como cantidad de equipos. Este es un ejemplo académico que simula 
un sistema comercial con calendarios y pagos reales.
